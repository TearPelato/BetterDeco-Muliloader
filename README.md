# Welcome to BetterDeco Project
BetterDeco is a decorative mod that adds over 200+ for indoor and outdoor to improve your world.
Brand new models and texture to a vanilla-friendly styled furniture mod.

# Features
- Over 200+ custom furnitures including small animations, sounds and working appliances
- Integrated compatibility with Everycompat, JEI and many more coming soon
- Dedicated Creative Tab filter system - Thanks to BlackGear
- Compatible with NeoForge & Fabric, Client and Serverside

# Updates and Supported Versions
BetterDeco adopts the following numeration starting from 2.0.0:
- 2.x.0 -> Major feature update including new features, bugfix, translations and more
- 2.0.x -> Small patches including bugfixes, translations and minor features or compatibilities
- 2.0.1.x -> Small patches dedicated for the version, for exaple: 1.21.1 need a small bugfix it will be called 2.0.1.1 because it's only for that version,
             fro comulative fixes ill be used the numbering above
- x.0.0 -> It's a major rework or new features that modifies current content. Likely 1 in a Year or 2

For the supported version BetterDeco will adopt this system:
- 1.21.1 -> Main supported version
- 26.1.2 -> One of the latest and most played and modded version
- Latest Version -> It's simply impossible to support all the latest versions, Mojang is rolling out a new version every 3 months and it's hard to push each update out
                    so after a new version all the past versions are outdated but not abandoned, bugfixes will be provided as well.
                    As of today, the latest version is 26.3 but will be outdated as soon as 26.4 is out.
